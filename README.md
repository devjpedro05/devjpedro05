## 📌 Projetos em destaque

### 🔹 Apolo Vídeo Inspeção - Sistema Web
Sistema web para gestão de inspeções por vídeo, com foco em monitoramento geoespacial e relatórios em tempo real.

**Stack:** Vue.js, Vite, Supabase, PostgreSQL, Google Maps API, Netlify, Docker

### 🔹 Apolo Vídeo Inspeção - Sistema Desktop
Sistema desktop para coleta e gestão de dados de inspeção em campo, com operação local e fluxo offline.

**Stack:** C#, WPF, EF Core, SQLite, .NET

Projeto acadêmico desenvolvido em Assembly (NASM) e C, simulando registradores, memória e execução de instruções.

**Stack:** Assembly, C, Arquitetura de Computadores
